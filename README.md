# Daybreak Cafe

[Live prototype](https://saichand24.github.io/daybreak-cafe/)

The root index.html and assets contain the GitHub Pages production bundle. Editable React source, setup, rule policy, demo steps and validation notes are in [source/README.md](source/README.md).

To develop: cd source, then npm ci and npm run dev. To validate: npm test and npm run build. The generated source/dist folder can replace the root production bundle when deploying. Payroll uses illustrative INR mock data.
